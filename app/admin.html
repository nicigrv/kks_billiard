    KI-Training: Kugeln festlegen

    Bilder entstehen nur, wenn ihr „Jetzt ein Bild aufnehmen“ drückt. Ihr legt die Kugeln fest: auf eine Kugel tippen, dann ihre Nummer. Fehlt eine Kugel, auf die freie Stelle tippen. Sobald der KI-Chip ein Modell hat, schlägt er die Kugeln schon vor – dann nur noch prüfen und „Passt alles“. Nur festgelegte Bilder werden zum Training benutzt.

    KI-Modell (Coral)

    -

    Die Kugeln (mit Nummer) erkennt ausschließlich der KI-Chip. Solange noch kein eigenes Modell trainiert ist, zählt der Pi nichts selbst – er nimmt nur Bilder auf, und ihr legt die Kugeln fest. Alle Bilder bleiben auf dem Pi gespeichert, auch verworfene.

    So kommt ein eigenes Modell auf den Coral: 1. Trainingsdaten laden. 2. Am PC oder in Google Colab trainieren (Anleitung: training/README.md). 3. Die Datei billard_edgetpu.tflite hier hochladen. Der Coral übernimmt sie sofort.

    Trainingsdaten laden Alle Bilder laden (auch offene und verworfene)
    Was die Kamera sieht

    Gelb = volle, blau = halbe, weiß = Weiße, grau = 8. Fehlt eine Kugel oder ist sie falsch markiert, wird das Licht oder die Kalibrierung das Problem sein.

    Kamera

    -

    Das Bild wird einmal geladen und auf dem Pi gespeichert (läuft danach auch offline). Danach unter „Tisch einrichten“ die vier Ecken des Tuchs antippen. Ohne Adresse läuft ein simuliertes Spiel, das schon eingerichtet ist.

    Tisch einrichten

    Tippe die vier Ecken der Spielfläche an, dort wo das Tuch auf die Bande trifft. Reihenfolge: einmal rundherum, beginnend an einer langen Seite.
